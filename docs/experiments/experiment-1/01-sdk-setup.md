# Experiment 1.1 — Flutter and Dart setup

## Aim
Install the Flutter SDK and verify the Dart toolchain.

## Procedure
1. Install Flutter using the official instructions for your operating system.
2. Add Flutter's `bin` directory to PATH.
3. Run `flutter doctor` in a terminal.
4. Resolve the checks required for your chosen target (Android emulator, browser, or desktop).
5. Verify Dart with `dart --version`.

## Expected result
The terminal reports the installed Flutter and Dart versions. Android toolchain warnings may remain until Android Studio and an emulator are configured.
