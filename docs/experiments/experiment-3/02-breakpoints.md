# Experiment 3.2 — Breakpoints

The sample dashboard uses these practical layout bands:

| Available width | Layout |
| --- | --- |
| Below 600 logical pixels | Compact phone layout |
| 600–899 logical pixels | Expanded phone / small tablet |
| 900 and above | Wide tablet / desktop-style content |

These are app design choices, not Flutter-mandated breakpoints. Use the constraints of the actual parent widget when possible.
