# Experiment 2.2 — Row, Column, and Stack

## Row
Used for side-by-side metrics. Wrap flexible children in `Expanded` to share available width.

## Column
Used inside cards to place headings, values, and progress indicators vertically.

## Stack
Used by the profile badge to overlay a small online-status dot on the avatar.

## Result
The dashboard combines these layouts into reusable components rather than keeping every element in one large build method.
