# Experiment 2.1 — Widgets and layout primitives

## Aim
Build interfaces by composing Flutter widgets.

- `Row` arranges children horizontally.
- `Column` arranges children vertically.
- `Stack` layers children on top of one another.
- `Padding` controls space around a child.
- `Card` groups related content.
- `Expanded` and `Flexible` distribute available space.

FitTrack applies these primitives to a dashboard with metric cards, hydration progress, and workout summaries.
