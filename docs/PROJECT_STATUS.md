# FitTrack Flutter Lab — Project Status

This repository is for the UI Design Flutter Lab experiments, implemented through a fitness and nutrition tracker called FitTrack.

## Experiment roadmap

1. **Experiment 1:** Install Flutter and Dart; practice Dart fundamentals.
2. **Experiment 2:** Explore Flutter widgets and compose layouts with `Row`, `Column`, and `Stack`.
3. **Experiment 3:** Build responsive screens with `MediaQuery` and `LayoutBuilder`.
4. **Experiment 4:** Navigate between screens using `Navigator` and named routes.

## App concept

FitTrack's sample dashboard will display daily workout activity, water intake, calories, and protein. Sample values are for UI demonstration only.

## Development checks

- Run `flutter doctor` to check the Flutter toolchain.
- Run `flutter pub get` to resolve dependencies.
- Run `flutter analyze` to inspect the Dart project.
- Run `flutter test` after tests have been added.
